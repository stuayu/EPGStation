# BML 用フォント

このディレクトリのフォントは [tsukumijima/web-bml](https://github.com/tsukumijima/web-bml)
(`node_modules/web-bml/fonts/`) に同梱されているものをそのままコピーしたもの。
データ放送 (BML) 描画に使う Kosugi / KosugiMaru フォント。

- ライセンス: `LICENSE.txt` (Apache License 2.0) を参照
- 著作者表記: `AUTHORS.txt` / `CONTRIBUTORS.txt` を参照

`web-bml` の依存バージョンを更新した際は、このディレクトリのフォントとライセンス
ファイルも `node_modules/web-bml/fonts/` から差し替えること。
